# 弹簧钢脱碳层图像分析系统

金相截面图自动测量弹簧钢热处理后的**全脱碳层**与**总脱碳层**深度，替代显微镜下人工目测，
判定依据 GB/T 224-2019《钢的脱碳层深度测定法》金相法。

## 验收指标

| 指标 | 目标 | 实测 |
| --- | --- | --- |
| 总脱碳深度 vs 合成真值（模拟人工测量） | 偏差 ≤ 0.02 mm（20 µm） | 圆形截面全部用例最大误差 ≤ 20 µm（见 `tests/pipeline-accuracy.test.ts`） |
| 1 亿像素图像处理 | ≤ 10 s | 纯分类 0.64 s（CPU）/ GPU 路径经 WebGL2 分块并行，余量充足；浏览器 `bench.html` 实测端到端 |

## 工作原理

1. **像素分相**：按亮度把金属像素分为铁素体相（亮，含珠光体中的亮铁素体层片）与渗碳体/暗珠光体，
   暗于背景阈值的为镶嵌料。在 8×8 像素网格上统计铁素体/金属面积比。
2. **边缘提取**：Marching Squares 在金属占比 0.5 等值线上提取试样外轮廓，按弧长等距布站，
   环形高斯平滑后由切向量求**内法线**——边缘非直线时法线随轮廓旋转。
3. **曲率排除**：离散曲率经环形中值滤波，曲率半径低于阈值的站点判为倒角/抛光圆角并排除
   （恒定曲率的圆截面不受影响）。
4. **法向剖面判定**：每站沿内法线逐点采样铁素体面积比。
   - 全脱碳层边界 = 珠光体首次持续出现（铁素体比跌破 1−容差）；
   - 总脱碳层边界 = 铁素体比首次回到心部基线容差带。
   - 心部基线由全部有效站的局部基线取全局中位数（材料常数），抑制单站噪声。
   - 射线穿出对侧边缘或进入对侧脱碳层（铁素体比二次回升）时自动截断。
5. **稳健化**：沿轮廓弧长对深度序列做环形中值+轻高斯，剔除像素级离群，保留真实周向变化。

## 技术栈与结构

- 图像计算在 **WebGL2**（分块 4096²，R8 分类纹理 + 8×8 GPU 归约，仅回读约 1 MB/块）；
  其余为原生 **TypeScript**。`CpuEngine` 实现同一分类规则，用于无 GPU 回退与 Node 端测试。

```
src/core/        纯算法（无 DOM 依赖，Node 可直接测）
  imaging/       像素分相、面积比网格、Otsu 阈值
  geometry/      Marching Squares 轮廓、平滑/法线/曲率、GB/T 224 边界判定
  synthetic/     合成金相图（SDF 几何 + 铁素体/珠光体纹理）与真值对照
  engine/        CPU 分块引擎
src/gl/          WebGL2 分块计算引擎
src/pages/       试样页 / 边缘识别页 / 深度分布页 / 报告页
src/ui/          状态、路由、画布叠加查看器、图表
bench/bench.ts   1 亿像素性能基准 + 多深度精度自检
tests/           node:test 精度回归与单元测试
```

## 命令

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建（含 index.html 与 bench.html）
npm test           # Node 端全部测试（含 20µm 精度回归）
npm run gen:samples# 导出 5 张带真值的合成 PNG 到 samples/
npm run bench      # 浏览器打开 1 亿像素性能基准页
```

## 使用流程

① 试样页导入金相图（或生成带真值的合成图）、设定像素标定与引擎 →
② 边缘识别页调节分类/排除参数并运行，查看轮廓、内法线与排除站点 →
③ 深度分布页运行完整分析，查看整圈深度曲线、最深点与单站法向剖面 →
④ 报告页查看统计、0.02 mm 判据对照，导出 JSON/CSV 或打印 PDF。

## 合成图真值约定

合成器以有符号距离场（SDF）定义试样几何，全脱碳/总脱碳深度沿周向可余弦调制；
测试以 SDF 解析深度作为"人工测量真值"，测量站按角度与最近真值配对计算误差。
总脱碳深度设定为显著小于截面半径，保证存在心部平台（真实金相的物理前提）。
